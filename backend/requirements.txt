# 🛍️ Meesho Clone — E-Commerce Web Application

A full-stack e-commerce web application inspired by the core shopping experience of Meesho.

## 🚀 Project Overview

This project provides an e-commerce platform where:

* Customers can browse products
* Customers can register and login
* Sellers can add products
* Products are stored in PostgreSQL
* Users are authenticated using JWT
* Customers can add products to cart
* Customers can place orders
* Sellers can manage their products

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS

### Backend

* Python
* FastAPI
* SQLAlchemy
* JWT Authentication

### Database

* PostgreSQL

### Additional Technologies

* REST API
* Pydantic
* Password Hashing
